# LXD Tools

**Practical tools for learning experience designers**

Built by [Tessa Angelika Mmaitsi](https://tessa-angelika-portfolio.vercel.app/) — Learning Experience Designer, Nairobi, Kenya.

---

## What this is

A small collection of practical tools and templates for learning designers doing the everyday work of designing, scoping and building learning experiences. These are not frameworks or methodologies — they are working tools for getting things done faster and with more consistency.

---

## Tools

### 1. Needs Analysis Generator (`needs-analysis/`)

A Python script that takes a brief project description and outputs a structured needs analysis document — audience, gap, objectives, constraints, recommended approach.

**What it does:** Takes free-text input about a learning project and structures it into a needs analysis framework you can hand to a client or stakeholder for sign-off.

**Why it exists:** Needs analysis is the foundation of good learning design. Having a consistent, structured output saves time and ensures nothing is skipped.

---

### 2. Course Outline Formatter (`course-outline/`)

A Python script that takes raw course content (a list of topics, notes or bullet points) and formats it into a structured course outline with module groupings, lesson titles and estimated durations.

**What it does:** Structures messy content notes into a clean course outline with consistent formatting, ready for stakeholder review.

**Why it exists:** Content experts often provide information in unstructured ways. This tool bridges the gap between subject matter and learning architecture.

---

### 3. Storyboard Scaffold Generator (`storyboard/`)

A script that generates a storyboard template in markdown or CSV format for a given number of screens/slides, pre-populated with standard storyboard fields.

**What it does:** Creates a blank storyboard framework with numbered slides, fields for narration script, on-screen text, visual notes, interaction notes and audio cues.

**Why it exists:** Setting up a storyboard from scratch for every project wastes time. A generated scaffold means you start designing immediately.

---

## Design philosophy

These tools are designed to:

- **Save setup time** so designers can spend time on the work that requires judgement
- **Enforce consistency** across projects and team members
- **Produce handover-ready outputs** that clients and stakeholders can read and approve

They are not AI-powered in any complex sense — they are practical scripts that do repetitive structural work so you do not have to.
